# 🔧 AI Predictive Maintenance System

An AI-based predictive maintenance system that analyzes sensor data and predicts machine maintenance requirements using Machine Learning.

---

## 🚀 Features

* 📊 Sensor data analysis
* 🤖 Machine Learning prediction model
* 🌐 Interactive web interface
* ⚡ FastAPI backend integration
* 📈 Real-time prediction support

---

## 🛠️ Tech Stack

* Python
* FastAPI
* Machine Learning
* HTML, CSS, JavaScript
* Pandas & NumPy

---

## 📂 Project Structure

```bash
maintenance-predictive-system/
│── app.py
│── model.py
│── model.pkl
│── sensor_data.csv
│── requirements.txt
│── templates/
│── static/
```

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/bhuvanesh2204/maintenance-predictive-system.git
```

Go to project folder:

```bash
cd maintenance-predictive-system
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python model.py 
python app.py
```
